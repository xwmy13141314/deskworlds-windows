Deskworlds · 桌面世界
========================================

一款 Windows 动态壁纸：把 7 个可交互的 3D 世界铺在你的桌面上。
鱼会游动、可投喂，桌面图标照常显示和点击。

【怎么用】

1. 解压整个文件夹到任意位置（建议放到 D:\Deskworlds 这类固定目录）。
2. 双击 Deskworlds.exe 启动。
   - 会弹出一个黑色控制台窗口，2 秒后自动最小化（这是正常的，不是报错）。
3. 按 Win + D 显示桌面，就能看到动态壁纸了。
4. 屏幕右下角系统托盘有"桌面世界"图标，左键点击可以：
   - 切换世界（河床/珊瑚礁/斗鱼/等离子球/锦鲤池/篝火/湖上风暴）
   - 投喂食物
   - 暂停 / 继续
   - 退出

【喂鱼的两种方式】

方式一（推荐）：点右下角托盘图标 → 投喂食物 🐟
方式二：桌面空白处右键 → 显示更多选项 → 喂鱼 🐟（桌面世界）

【退出的三种方式】

方式一（最快最可靠）：在桌面按快捷键 Ctrl + Alt + Q，立即退出。
        无论托盘图标是否正常，这个一定能退出，推荐记住它。
方式二：桌面空白处右键 → 显示更多选项 → 退出壁纸 ❌（桌面世界）
方式三：点右下角托盘图标 → ❌ 退出
        （如果托盘图标卡住没反应，用方式一或方式二。）

【常见问题】

Q: 双击后什么都没看到？
A: 动态壁纸没有窗口，铺在桌面最底层。按 Win + D 就能看到。

Q: 点托盘退出没反应？
A: 用方式二（桌面右键 → 退出壁纸），或方式三。这是 Windows 托盘
   偶发的图标残留问题，右键退出不经过托盘，绝对可靠。

Q: 提示缺少 WebView2？
A: Windows 11 自带。如果是 Windows 10，请到微软官网搜索
   "Microsoft Edge WebView2 Runtime" 下载安装（免费）。

Q: 想开机自动启动？
A: 把 Deskworlds.exe 的快捷方式放到
   %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup 文件夹即可。
